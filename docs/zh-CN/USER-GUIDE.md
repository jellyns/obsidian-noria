# Noria 用户手册

**语言**：[English](../USER-GUIDE.md) | 简体中文

Noria 把日常记录、知识积累、计划、执行与复盘连接到同一个 Obsidian 工作台中。它以普通 Markdown 为内容基础，通过可配置主页、任务看板、任务时间轴、日历、习惯、趋势统计与复盘中心，帮助你看清当前状态、专注下一步，并让长期积累持续服务于行动。

本手册从首次安装开始，依次介绍各模块、常用工作流、故障排查以及高级扩展。插件概览和版本信息见 [中文 README](../../README.zh-CN.md)。

## 1. 安装与初始化

### 1.1 安装要求

Noria 当前为桌面端插件，最低支持 Obsidian `1.5.0`。

通过社区插件市场安装时，搜索 **Noria** 并启用即可。手动安装时，只把 GitHub Release 中的三个文件放入：

```text
.obsidian/plugins/noria/
├── manifest.json
├── main.js
└── styles.css
```

Obsidian 在保存设置后会生成 `data.json`。不要把源码仓库中的 `src/`、`tests/`、`scripts/` 或 `node_modules/` 复制进用户插件目录。

插件界面跟随 Obsidian 语言；无法识别时回退英文。

### 1.2 选择工作区方式

首次打开“设置 → Noria → 总览”时，选择一种方式：

- **标准工作区**：适合新库、测试库，或希望把 Noria 内容集中在 `Noria/` 下的用户。
- **自定义路径**：适合已经有 Inbox、Projects、Diary、MOC 和模板结构的知识库。

IPARA 不是第三种 profile。已有 IPARA 知识库应选择“自定义路径”，再把 Noria 清单与工作流映射到 `02_Areas/Noria/`，把内容目录映射到已有目录。

### 1.3 初始化流程

Noria 不会在启动时静默创建或移动文件。建议按以下顺序完成初始化：

1. 查看工作区预览和缺失项。
2. 检查 Inbox、Projects、Diary、模板和清单路径。
3. 确认计划创建的文件和父目录。
4. 点击初始化或修复。
5. 打开主页，在“Noria 工作区”项目中记下一步；项目卡的 **+** 给当前项目添加任务，卡片设置用于管理项目。
6. 勾选完成或打开任务详情，再查看源笔记、日记和看板中的同一条任务。

初始化补齐工作区文件和入口，不填入示例完成记录、打卡或截止日期。公开配图中的演示数据来自独立示例库。

### 1.4 初始化后的第一轮检查

- 主页可以打开，默认头像在未指定时使用 Noria 图标。
- 任务看板四个视图可以切换。
- 任务时间轴无需先打开任务看板即可加载。
- 日历创建的周期笔记进入正确路径。
- 习惯、倒计时、项目和 MOC 入口可打开来源文件。
- 从顶部日记入口切换到复盘，日、周、月、年模式均可选择。
- 新安装时天气默认关闭；第一次显式初始化工作区后启用，后续修复会保留用户选择。需要时配置位置或 provider。

## 2. 主页

通过“添加卡片 → 交互”，可以选择已有交流内容或新建问题。支持单选、多选、文本、数字和日期；卡片中的铅笔按钮用于编辑问题、选项和默认值。你的回答保存在 Markdown，外部 Agent 可通过 Noria 接口读取并回应，结果仍显示在原卡片里。保存回答本身不会启动 Agent。同一内容放到多个页面时共享问答；问题更新后保留草稿，先核对再继续。

顶部「页面设置 → 管理页面」支持入口改名、换图样、排序、显示／隐藏及设置默认入口，也可以新建空白或趋势统计页面。进入新页面后用「添加卡片」自由组合现有卡片；各页面布局独立，卡片仍读取原来的笔记和任务。隐藏卡片可从卡片库恢复，移除自定义页面不会删除源笔记。日记、日表保留各自完整功能。默认入口用于新工作台；恢复已有工作区时继续原页面。

顶部页面入口以图标显示，悬停或键盘聚焦时显示名称，当前页面保持选中背景。用 Tab 进入导航后，左右方向键移动焦点，Enter 或空格打开页面；Home／End 移到首尾。窗口较窄时，未显示的页面可从「更多页面」菜单打开。图标在「页面设置 → 管理页面」修改。

主页是 Noria 的中心工作台，不是固定的功能集合。它负责把当前状态、下一步、知识入口和阶段观察组织在一张可配置页面中。

![Noria 主页](../assets/zh-CN/home-dashboard.png)

### 2.1 首屏结构

默认首屏按以下顺序组织：

1. 身份、名言、天气和概览指标。
2. 在顶部导航切换主页、日记，打开日表、日历；末尾页面设置提供“添加本页卡片”和“调整本页布局”。
3. 待办、Inbox 与倒计时三列工作卡。
4. 项目和 MOC 导引。
5. 趋势统计；复盘从日记进入。

默认顺序只是起点。每个主要卡片都可以作为一级小组件独立调整。

### 2.2 捕捉与任务输入

主页不再重复放置捕捉与任务输入条：

- **捕捉**：在 Timeline 中记录想法、线索和临时记录。
- **任务**：通过待办卡的新增按钮添加。

普通状态下悬停卡片或聚焦底边把手即可调整高度；布局编辑时把手持续显示。主页和日记使用相同方式，窄窗格也可调整；卡片菜单提供自动高度。捕捉后不要求立即分类。

卡片右边缘可拖动调整宽度，支持十个吸附档位；松手保存，Esc撤销。`… → 布局 → 宽度`提供六个常用比例和细调滑杆；键盘方向键调整滑杆后按Enter应用。窄屏自动铺满不会覆盖保存宽度。专注圆盘按底部按钮行上方的可用区域居中放大。

### 2.3 待办

主页待办默认按节奏组织，强调当前可做的事情，而不是持续展示截止压力。

- 未完成任务使用更明确的字重。
- 首个未完成分组显示组内数量与当前范围未完成总数，例如“现在 17 · 23”，标题栏不再放数量。
- 列表下方显示已完成分组，默认展示最近3项；更多可展开。勾框和删除线提供完成反馈，取消勾选可恢复任务。
- 建议优先处理的任务自然排在前面并使用轻量标记，不额外生成建议框。
- 点击任务直接打开来源；悬停显示日期、标签、项目和来源等详情。
- 日、周、月、年范围切换继续保留，窄卡自动收为当前周期选择入口。

任务无法完成时可以在第二天继续，不需要把延期本身设计成惩罚。

### 2.4 Inbox

Inbox 卡片显示 Inbox 目录中的输入，标题栏按我／SI 和动作筛选。点击条目在旁侧阅读原文，继续选择会复用同一阅读位置；在列表中按上下键切换，原文可直接编辑。固定阅读笔记后，新选择在同侧另开标签。按住拖到两侧动作区安排处理；队列 Base 使用同一 inbox-work 属性。具体要求写在原笔记，选择 SI 不会自动启动外部助手。操作步骤见[处理 Inbox](#113-处理-inbox)。

### 习惯卡片

习惯卡片默认显示今天和近期独立日期格，宽卡最多显示近 7 天，窄卡减少历史列，保留名称与今天操作。数值型直接显示今天的实际数值及单位，零值不会显示为空。点击右上角历史图标可展开较长历史并横向查看，再次点击回到近期；展开范围默认 21 天，可在 **… → 卡片设置 → 显示天数**调整。点击日期格补记，点击习惯名称调整参数。

![主页习惯卡](../assets/zh-CN/home-habits.png)

### 2.5 倒计时

显示“还有 n 天”，当天显示“就是今天”；主页只显示尚未到期的项目；已到期和已归档项目可在管理面板中查看。**+** 新增，点条目编辑名称、开始和截止日期。进度按实际开始、截止日期计算；没有开始日期的旧记录不显示虚构进度。

有色进度条只展示时间进度。卡面不常驻起止日期或设置提示；点击条目打开完整编辑界面，修改名称、开始与截止日期。归档和恢复在管理面板中完成，原记录保留在倒计时 Markdown；任务来源的倒计时修改原任务。

### 2.6 项目与 MOC

- 点击项目选择任务，名称保持单行；下拉选择器可查找更多项目，不再常驻搜索图标。标题行的笔记图标打开当前项目主笔记，时间轴图标查看其任务安排。项目卡标题的 **+** 展开任务输入，保存后可继续录入，`Esc` 收起；未提交输入和当前项目保留。
- MOC 入口按网格对齐，随卡片宽度调整列数。小色点标识主题，同名 Canvas 使用独立图标。显示名称省略末尾 `·MOC`，源文件名保持原样。
- **+** 选择已有 Markdown 或 Canvas 文件；**… → 管理内容**调整顺序、颜色、路径或移除入口。移除入口会保留源文件。库内文件或文件夹改名后，已保存的入口路径会跟随更新；失效入口可以重新选择对应文件。

项目、MOC、工作流和队列的资料入口会保留主页，并复用已经打开的 Markdown、Canvas 或 Base 标签页。Ctrl/Cmd 点击或中键另开标签，Ctrl/Cmd+Alt 点击并排打开；悬停预览遵循 Obsidian 的“页面预览”设置。主页保留入口，不复制完整项目或知识正文。

![主页 MOC 入口](../assets/zh-CN/home-moc.png)

项目管理先显示名称和阶段，点一项再编辑。新增时可选择已有笔记，或明确选择“新建项目笔记”；输入错误的已有路径不会偷偷创建文件。隐藏、完成与移除入口均保留源笔记。

### 2.7 主页小组件

主页、日记和自定义页面支持一张高卡旁上下叠放多张卡。拖动卡片标题空白处，靠近另一张卡的上／下边缘可叠放，靠近左／右边缘可独立排布；预览确认位置，松开保存，`Esc` 取消。也可用 **… → 布局 → 叠放到…** 选择目标和上下位置，**独立排布** 将当前卡移出组合。组合共用宽度，每张卡单独调整高度；窄窗口自动排为单列，隐藏后恢复仍保留组合。设置只保存在插件中，不修改笔记正文。

在顶部导航右侧打开 **页面设置 → 添加本页卡片**，选择内置功能、笔记 / Base、统计或可用的第三方组件。主页、日记和自定义页面使用同一入口。选择后配置并预览真实内容；隐藏的卡片也能从这里恢复。 卡片库支持按名称和用途搜索，右上角“统计模板”进入统计库；“全部样式”先列基础图形，支持搜索图形名称。从统计编辑页返回时保留分类、搜索词和选中模板，未应用的修改会先让你选择继续编辑或放弃。

在卡片库右上角点击 **统计模板**，按「推荐模板」「全部样式」「我的模板」选择。「主页与趋势统计」收录统计总览、笔记趋势、任务趋势、习惯打卡、两种年度热力图、标签分布和日常记录，保留现有统计与交互，可添加到主页和自定义页面，也能保存为自己的模板；其中统计总览、笔记趋势、任务趋势、两种热力图和日常记录也可添加到日记，默认跟随所选日／周／月／年。标签分布反映当前资料，保留在主页或自定义页面；日记使用已有的习惯记录卡，图库会说明这两项限制。「基础图形」的 11 种样式各有默认配置，记录模板优先使用已有字段；缺少状态字段时需自行选择属性。图库展示样式示意，编辑器读取真实数据。「最近一段时间」按含今天的最近 N 天计算；基础图形之间切换保留范围和筛选。模板保存配置，不复制源数据，移除模板不会影响已添加的卡片。主页成品卡保留原有范围与指标设置，不等同于可任意更换数据源的基础图形。

「分段占比」将旧版百分比分段条恢复为可配置图形：选择当前记录属性，范围设为「跟随当前页面」即可用于日／周／月／年日记；点击色段或分类明细可查看对应记录。缺失值不计入分母，有重叠的分类和负值不能作为互斥占比，计算方式限数量、合计或状态分布。旧周期统计的分布图也复用同一绘制组件。

环图可直接点击扇区或引线标签查看、修改对应来源；隐藏图例后仍可使用标签，键盘 Tab 选中分类后按 Enter 或空格打开。悬停或聚焦分类会突出对应引线，临时显示完整名称、数值和占比，离开后收起；只读环图也支持键盘查看。分类较多时标签区按需增高；极小占比保持真实大小，可从标签或分段图的分类明细进入，不必精确点击细小色段。左右均衡布局的跨侧引线从环外绕行。横向条形共享同一起点和轨道宽度，便于比较数值。

热力图和按日状态格标出月份，跨月日历分别按星期对齐。长热力图与连续色带首次打开时显示选中日期；修改记录或来源刷新后，保留日期和滚动位置。Tab 进入当前日期，左右键切换，Home／End 到首尾；长热力图左右移一周、上下移一天，月历上下移一周。数值热力按从小到大的数值着色，图例显示范围；零值、未记录和多个状态分别保留，不把负值按绝对值变成高强度。

主页的习惯／工作量热力保留独立的年度视图，跨年范围逐年显示。Tab 进入日格后，左右键切换一周、上下键切换一天，Home／End 到该年首尾；读数提示只在聚焦时显示。新建笔记按来源的创建日期逐日统计，不把周／月汇总值当成某一天。「完成任务」与任务完成趋势共用已配置的任务范围和完成日期；明确完成日期优先，日记内未标日期的任务沿用日记日期，没有可用日期的完成项不放入日格。「日记字符」统计当前日记的非空白字符，含属性和 Markdown 标记；后续编辑会改变数值，不代表当天新增字数。

「活动强度」将每日完成任务、新建笔记、日记字符分别按范围内日峰值归一，以 35%、35%、30% 加权。颜色和活跃日期用于范围内比较，不代表工时或效率；切换范围可能改变颜色与排名。底部不再把混合分值显示为产出数量。打开工作量热力图右上角「… → 统计口径」，可查看当前指标解释，以及没有可用日期的完成任务数；切换指标后，说明随之更新。主页、日记和自定义页面的入口相同。

「周期趋势」提供“笔记与字数”和“任务数量与完成率”两个双轴模板，可用于主页、自定义页面和日记。范围默认跟随当前页面，也可选固定范围或最近 N 天；卡片内可临时切换日／周／月，持久的默认粒度在卡片设置中保存。自动粒度在 45 天内按日、180 天内按周、更长范围按月。任务沿用活动口径：已完成任务按完成日期归入，未完成任务按到期／计划／开始日期等归入；汇总后的完成数除以活动任务数，不平均每日百分比。无任务时段不显示完成率；“数值与统计口径”保留完整周期键、两列指标和计算说明。图例标明左右轴，鼠标或触点定位可查看完整期间与精确数值；键盘左右键选时段，Home／End 到首尾。调整卡片宽度保留选中时段与数值区展开状态。点击图表、按回车或选择读数旁的“查看来源”，可查看同一时段的来源：任务分为已完成与未完成，笔记分为新建笔记与日记字符。正式卡片打开原笔记，任务定位到当前行；配置预览只读，返回后保留未应用的设置。笔记图的两列分别为新增笔记数量与对应日期的日记字数；字数是含 Markdown 标记的非空白字符数，并非当天新增写作量。

主页的**专注卡**提供「计时／回看」切换，两种视图保持相同高度，切换不会暂停或重启计时。今日累计或当前计时状态放在标题行，表盘居中，底部只保留一行：计时时为任务入口和控制按钮，回看时左下角为日期按钮，点击打开日期选择，右侧为计时控制；时段与来源放在卡片更多菜单中。计时方式与状态合并在盘内；尚未开始时可点击切换方式。回看时仍可暂停、继续或结束当前会话。独立专注时间环可在统计页查看，新建「趋势与统计」页面也会包含它；主页／日记按需手动添加，不再自动补入独立环。已有自定义卡片不会因升级删除。

**专注卡** 可通过「添加卡片」放到主页。计时视图的任务行切换番茄／自由计时；番茄盘面显示已用比例，自由模式显示累计时间。点击任务名称选择对象，来源图标打开原笔记。也可把主页待办或项目、日记中的任务标题拖到专注卡：空闲时直接开始，正在专注时先确认切换或取消，已有时间保留；重复拖入同一任务不重开。拖动不移动原任务、不改变安排，也不会完成任务。任务来源已改变或无法唯一定位时，刷新后重试；键盘可在任务编辑器使用专注菜单。

**专注时间环** 可从通用统计模板中添加到主页、日记或自定义页面，读取计时器及普通 Markdown 中的实际分段。范围默认跟随页面；日期按钮在范围内切换单日，默认先看最近有记录的一天。暂停不计入，跨午夜按当天截取，重叠时长只计一次；没有记录显示“—”，空白不代表空闲，缺少分段的旧记录不推算。悬停查看时段、点击固定选择；方向键和 Home／End 切换分段，回车打开来源，也可使用日期旁的 **时段与来源** 查看密集短段。默认中心显示合计，选段后显示该段时长和任务名；中心任务名跳到原笔记对应记录，悬停查看完整时间。在卡片设置中开启 **对照任务安排**，外侧细虚线显示明确的任务安排，内侧实线显示实际专注。新建时间环模板默认开启，已有卡片保持原设置。中心分别显示实际专注与安排时长，不相加、不换算成完成率。仅有日期或截止要求的任务不推算时长，含义不明确的旧 start/due 也不推算；取消的安排排除，已完成任务的安排保留用于回看，重叠安排只计一次。点击安排标题定位原任务，点击专注标题定位实际记录。

任务看板、横版／竖版时间轴及专注时间环共用任务分类色。按任务原文中第一个有效分类标签取色，先匹配完整标签，再匹配其首级标签；任务状态和逾期仍保留原有提示。外观设置支持中文及层级标签。专注只有能唯一对应原任务时才继承颜色，同名歧义保留默认色；单张统计卡明确设置的强调色优先。

专注记录在 Obsidian 阅读视图及 Noria 渲染的正文中，默认显示任务名称和实际时长；展开查看计时方式及起止分段，点击任务名称打开原笔记。暂停不计入时长，短记录按秒显示，跨日分段保留日期。精确时间仍在原 Markdown 中；源代码／编辑模式不隐藏这些原始内容，修改后统计仍按原文回读。

**目标进度环** 将1至4个指标放在同一统计卡片中，默认是任务完成和习惯达标。卡片设置可逐圈更换为任务、习惯或日记数值，并填写名称；任务可按计划或截止日期纳入，习惯沿用历史应打卡计划，数值可按合计或平均值计算。数值目标适用于当前整个范围，切换日／周／月不会自动按天数放大；单位留空时沿用对应记录设置。各圈独立计算，不合成不同单位的总完成率。点击图例或环切换指标，中心查看实际值与目标；点击中心或 **… → 当前指标与来源** 打开明细、再跳到原笔记。方向键及 Home／End 切换，回车查看来源。超额完成保留真实百分比，弧线最多一圈；无记录、未设目标和0分别显示。原文修改会刷新读数并保留选择和键盘焦点，部分数据无法读取或值不合法时明确提示，不用部分结果冒充完整完成率。

在统计设置的 **图表外观** 中调整配色、自定义颜色，以及适用于当前图形的密度、纵轴范围、采样点或图例。折线与柱图可填写同单位的参考值；数据超出指定刻度时会扩展范围并提示，不截掉真实值。**保存当前外观** 可供其他统计复用，只应用显示设置，不改变数据来源、筛选或参考值；移除预设也不会改动已应用的卡片。空折线／柱图不展示空坐标，日记统计仍可选择日期补记。

每张卡右上角 **…** 将内容管理与布局操作分开：宽度示意、上下移动、折叠、自动高度、复制和隐藏。复制出的卡片拥有独立配置。未指定高度时并排卡片自然对齐；底边把手可单独调整高度，窄栏仍然有效。主页布局独立；日、周、月、年分别共用各自布局，切日期只切内容。

Dataview 卡片选择包含查询的笔记，通过 Obsidian 原生插件详情安装或启用依赖。两个卡片可以使用不同笔记；停用依赖只影响相应卡片，重新启用后可恢复。笔记 / Base 卡片复用原生渲染。其他插件必须提供适配接口或可嵌入笔记内容；不保证任意完整插件界面都能嵌入。开发者见[卡片接口](../CARD-PROVIDERS.md)。

### 2.8 外部 Markdown 工作台

Markdown 小组件可以读取外部 Agent、RSS 流程或其他脚本生成的每日简报、当前建议、每周回顾和项目监控文件。Noria 负责展示、来源跳转和新鲜度提示，内容仍由对应外部流程生成。

### 藏馆与主页快捷入口

日常浏览从顶部的藏馆进入；主页只保留你主动加入的快捷入口。两者都读取原作品笔记，不需要另建收藏副本。

| 入口 | 用途 | 点击作品后 |
| --- | --- | --- |
| 顶部藏馆 → 作品 | 浏览收藏、阅读、进度与关联笔记 | 进入作品详情 |
| 主页快捷入口 | 随手打开主动选中的作品或其他内容 | 优先打开已关联的阅读／播放入口，没有时进入详情 |
| 页面设置 → 添加本页卡片 → 作品列表 | 在其他页面放一份简单列表 | 打开作品原笔记 |

#### 先打开藏馆

顶部导航的书架图标打开 **藏馆**。页面标题旁的藏馆、打开的书、胶片、唱片和手柄图标切换全部、图书、影视、音乐、游戏五个子页面；悬停显示名称，聚焦后可用左右方向键切换。标题与导航位于卡片外，切换时作品及“近期完成”统计一起切换范围。

第一次使用时，在“全部”子页面的 **作品** 卡片中选择已有目录；其他子页面的作品目录留空时跟随该目录，也可单独指定，无须移动笔记。每个子页面独立保存卡片组合、顺序、宽度和设置；顶部 **页面设置 → 添加本页卡片** 操作当前子页面。切换时保留各自的搜索和详情状态，重载后恢复当前分类；卡片被修改而需要刷新时沿用共用编辑保护。

首次载入作品时，优先显示笔记中已有的“进行中”或 `In progress`；两者都有时优先采用当前界面语言对应的值，没有这两种状态时显示全部。点击“全部”可查看完整收藏。此选择不翻译或改写笔记的状态，自定义状态仍可直接筛选。

页头右侧切换 **封面／详细** 视图。封面默认只显示封面和标题；详细视图默认显示创作者、进度和摘要。摘要优先摘取指定评语章节，没有评语则摘取指定简介；简介章节不存在时沿用旧 description 字段。摘要注明对应章节名称，只展示原文片段，不生成新内容。旁边的 **显示设置** 可以分别开关创作者、进度、评语／简介，封面视图还可调整尺寸；每个分类独立记住选择，切换视图保留当前搜索和筛选。在详细视图或开启进度显示后，直接点击进度文字修改；只有有效的图书页码与总页数才显示比例，未知总页数只显示当前页。非图书使用状态，不从时长推算百分比。旧评分字段保持原含义，个人评星尚待接入。

作品卡片内的状态筛选、搜索与添加操作放在同一工具行，空间不足时自然换行。搜索无结果时可清除筛选；点击作品进入详情，返回时保留当前分类。封面保持比例、按底边排列；快捷入口按钮在悬停或聚焦时出现，已加入主页的作品持续显示。其他自定义统计卡片仍遵循各自配置的数据来源，不自动改写其统计口径。

点击封面时，封面从陈列位置连续移入详情，返回时回到原作品并恢复焦点。分类切换使用短暂过渡；快速反向操作、滚动或切换分类会取消旧过渡，不阻塞操作。系统启用“减少动态效果”后直接切换。音乐保留方形封面，显式播放入口显示“聆听”；没有完成日期时，统计只显示简短空状态。

#### 收录作品与模板

藏馆读取指定目录中的普通 Markdown；在 Obsidian 或外部编辑器中添加、修改作品笔记，Obsidian完成文件检测与索引后界面自动更新，无需再次导入或手动刷新。文件需要位于作品卡片配置的目录内，并带有支持的作品身份标签；当前搜索和筛选仍会影响是否显示。作品用 `book`、`movie`、`music`、`game` 等已有身份标签识别，具体分类直接使用标签；评分、进度与封面仍保存为属性。没有作品身份标签的关联笔记不作为独立作品收录。外部修改类型后，已打开详情的阅读／观看等动作与编辑字段同步更新；正在编辑的评语保持内容及光标，完成编辑后采用新类型的章节配置，不改写或删除原章节。

也支持中文身份标签：图书用 `图书`／`书籍`，影视用 `电影`／`影视`／`电视剧`／`动画`，音乐用 `音乐`／`专辑`／`歌曲`，游戏用 `游戏`。可写在 `tags` 属性或正文标签中，原标签保留，不自动改成英文。身份标签不计入分类分布；例如《三体》的 `[图书, 科幻]` 与《星际穿越》的 `[电影, 科幻]` 都能从「科幻」筛选找到。身份按完整标签匹配，`电影研究`、`电影/科幻` 不自动视为电影作品；后者可另加 `电影` 标签。

右侧 **＋ 添加作品** 可填写名称与已有保存目录；图书、影视、音乐、游戏子页面直接承接当前类型，“全部”页和独立作品卡片保留类型选择。目录可选择卡片作品目录下的子目录，查重覆盖整个卡片目录。同名作品显示原路径，点击即可打开；确实是另一版本时选“另存一个版本”，再填写文件名。相同 ISBN 或来源版本仍会返回原记录，避免重复收录。添加成功后打开新作品；若保存期间已关闭窗口，则只提示收录完成，不跳转。未填状态不会自动成为“进行中”。填写中点外部或取消，当前卡片保留临时输入，各分类分开；页面重建或插件重载后不保证恢复。

书籍可输入名称、ISBN 或 Open Library 链接，点击 **查找资料**；按书名找到作品后再选具体版本。无须先查询，也可展开“作品资料”手动填写作者、出版社、出版日期、ISBN、页数及来源／封面链接，再点 **添加**。短字段并排，长链接独占一行。作者姓名按版本中的作者标识补齐；未取全时在作者字段提示，可手动补充或修正。重新查找保留已填资料，选中具体版本后才替换；“不使用这些资料”可清空补充资料，手动入口仍保留。影视、音乐和游戏目前采用手动收录；已有音乐笔记的 `artist` 可直接显示并搜索。

在 **添加作品 → 模板** 中按类别选择库内 `.md` 文件，文件名不要求特定后缀。关闭模板设置后回到添加窗口，已填名称、目录和资料保留。**显示设置 → 作品模板…** 和作品的 `…` 也提供此入口。路径旁的文件编辑图标可「保存并编辑模板」，将当前配置保存后直接用 Obsidian 编辑原模板。创建新作品时读取模板最新正文和自定义属性，实际输入的作品资料优先；模板已有同类别身份标签时直接沿用，不再追加另一种写法。支持 `{{title}}` 与 `{{date}}`，不执行模板脚本。更换或修改模板只影响后续创建，已有作品不会被重写；模板缺失或类型不符时停止创建。

正文默认「跟随笔记」，保留原有章节顺序、下级标题及无标题文字；新增章节无需注册或勾选。简介与评语的提取名称、按需指定展示章节放在折叠的 **展示与摘要** 中。已有主动勾选的章节配置继续保留，可切回「跟随笔记」。同名重复章节仍可阅读，请在原笔记中编辑以避免定位歧义。

在作品菜单选择 **编辑作品资料**：图书可修改作者、出版社、ISBN、总页数和出版日期；影视可修改导演，音乐可修改艺人，游戏可修改开发者，后三类还可修改年份。来源与封面按需展开。修改项显示原值，可逐项还原；保存只写改过的字段，保留状态、当前页、评分和正文。清空输入表示清空该字段。封面可填库内图片路径、双链或 HTTP(S) 链接；若原笔记另有 `image`，会提示其优先显示。资料已在别处修改时，当前输入保留在弹层中，核对后重新打开编辑。图书还可展开 **查找版本资料**，按名称、ISBN 或 Open Library 链接查找并选择具体版本。各字段旁显示来源值，点击 **采用** 后才进入当前输入；选中版本本身不替换输入、不写笔记。重新查询会清除来源建议，但保留手动修改和已采用的值；来源链接也可单独选择。

封面由作品笔记的 `cover` 属性指定，可填图片双链、库内路径或 HTTP(S) 图片网址；旧 `image` 属性继续优先。修改笔记里的引用后，列表和已打开详情随索引更新；没有封面、本地图片不存在或图片加载失败时显示默认封面。同路径替换本地图片、删除或恢复图片后，已打开的封面自动更新，不打断评语编辑；失败的网络图片会在恢复联网时重试，成功的图片不重复加载，不定时轮询远程网址。Noria读取这些资料，不会因新增笔记而自动联网补全封面。来源笔记被删除、移出收录目录或去掉所有作品身份标签后，未编辑的详情返回列表；有正在编辑的内容时保留输入并禁用失效操作。删除后点击返回，会先把未保存输入写入Obsidian文本备份，不重新创建被删笔记。Obsidian原生改名保留当前编辑并改向新路径；外部程序若把改名报告成删除与新建，则按原文件失效处理，不猜测两个文件的身份。

#### 阅读、进度与关联笔记

作品详情的 **关联入口** 与菜单中的 **更改入口** 共用入口编辑框；输入框旁的文件夹图标选择库内文件，也可粘贴链接。保存后焦点回到阅读／观看／聆听／启动按钮，未改入口时保留原笔记格式。

图书的列表与详情使用相同页数：明确填写 `pageprogress: 0` 会显示第0页；未填写状态或页数时，列表省去该行。详情的「进度」位于阅读按钮旁，影视、音乐和游戏使用「状态」。填写后按钮显示已有状态或页数，仍可直接编辑。已知有效总页数且尚未到末页时显示细进度条；没有总页数或当前页超过总页数时只显示当前页。按书内页码记录进度，PDF阅读器的位置单独保留；样章的PDF页数不作为全书总页数。到末页不自动填写完成日期、状态或评分。非图书不从时长推算完成百分比。清空进度后，列表焦点返回作品标题。

详情中可更新进度、填写可选的完成日期、关联实际打开的文件或链接，并打开相关笔记。状态与页数在同一行显示，点击可修改；作品菜单中的“编辑作品资料”修改图书作者、版本和总页数。保存后更新显示并保留操作焦点，保存期间暂停输入；发生冲突时保留未保存内容并提示核对原笔记。封面下按类别设置展示简介、评语及选定的其他二级章节，完整作品笔记通过“关联笔记”标题右侧的文件图标打开，与添加关联笔记按钮并排；悬停或键盘聚焦可查看名称。章节旁的铅笔就地编辑，停止输入后自动保存，也可点击完成或按 Ctrl/Cmd+Enter 回到阅读；中文输入法组词期间暂停自动保存。修改写回同一 `.md` 的对应章节，不影响未展示内容；其他章节的外部修改保留，同段冲突则保留当前输入并使用 Obsidian 文本备份保存失败草稿。请复制草稿并核对原文。旧 `description` 简介在指定章节不存在时继续显示，编辑仍写回该字段，不自动复制到正文。普通反向提及另行折叠。作品入口单独保存在 `media-open`，支持库内文件（含页码或章节定位）、网页及 Obsidian／Steam／Zotero 链接，不把资料来源 `source` 当成作品入口。

详情中的长简介默认显示约六行纯文字预览，点击 **展开简介** 阅读完整 Markdown 和链接，再点击 **收起** 返回。短简介完整显示，不增加按钮；编辑始终打开完整章节。收展不修改原笔记，窄窗格会重新判断是否需要收起。

零散感想可直接写在作品主笔记中；需要独立成篇时再建立关联笔记。日期记录使用 `YYYY-MM-DD 标题.md`，同日同主题需要区分时再加入已知的 `HHmm`；长期主题使用稳定名称。既有独立感受笔记继续关联，不自动合并、改名或搬动。移动或改名时按 Obsidian 提示维护内部链接。日记中的日期 Base 汇总独立日期文件；主笔记内部的日期段落尚不参与该汇总。

主笔记下方的 **关联笔记 → ＋** 提供“新建关联笔记”和“关联已有笔记”。新建只填写名称，创建后直接打开 Obsidian 原文编辑；默认放在作品同目录，写入 `related` 链接，不强制日期、体验标签或单独记录目录。同名文件不覆盖，可使用关联已有笔记。已有主题笔记保留原位置。列表显示标题、实际文件名日期和原文摘要，修改、改名或删除后更新；没有日期的笔记不补日期。普通提及单独折叠，展开后才读取摘要。

作品与关联笔记已在 Obsidian 打开时，Noria 会回到已有标签；未指定页码的阅读入口保留阅读位置，带 `#page=7` 等定位的入口仍跳转到指定位置。直接修改作品 Markdown 后，已打开详情的标题、封面、分类、进度和阅读入口会局部更新，保留正在编辑的评语及光标。

已关联的本地文件不存在或入口格式无效时，从主页或作品详情点击都会打开该作品的入口编辑框，保留旧地址并提示重新选择。取消不修改原笔记；保存新入口后，下次点击即可直接打开。不因入口失效创建替代文件，也不把作品资料来源当作阅读地址。

#### 分类与统计

作品搜索框旁的 **筛选图标** 优先显示已有分类标签，「未标注」表示没有分类标签，作品身份标签不计入。只有原笔记存在 `genre` 类型值时，才出现「类型（属性）」选项。同组多选匹配任一项，类型与标签之间需同时满足。筛选与作品搜索、状态条件组合使用，状态旁的数量跟随当前搜索和分类。已选条件可逐项取消或清除；零结果保留条件，空状态的「清除筛选」同时清除搜索、状态与分类。

作品详情返回、分类页来回切换和原笔记更新会保留当前分类条件；重新创建页面或重载插件时不作为已保存视图恢复。下方统计仍表示整个收藏范围，不随列表筛选改变。已有 `genre` 保留，不需要为使用分类重复填写；标签按完整名称匹配。新增作品分布卡默认按标签统计；已保存的统计依据保持原选择，可在卡片设置中更改。

打开作品后，点击详情中的分类文字（未填写时为「添加分类」）即可编辑标签。仅在原笔记已有非空 `genre` 时显示「类型（属性）」，不会因编辑标签自动创建该字段。多项用中英文分号分隔，输入时可选择已有分类；修改后可逐项还原。保存只更新改过的属性，列表筛选和分布图随原笔记刷新。作品种类标签自动保留，正文标签只读并提供原笔记入口。已有标签格式异常时先在原笔记修正；分类被其他编辑修改时保留当前输入并提示核对，取消不写入。

藏馆默认上方通栏浏览作品，下方并排展示「近期完成」和「作品分布」；窄窗口改为上下排列。详细视图在宽卡片中排为两列，窄卡片恢复单列。音乐默认展示作品和分布。旧版未调整过的默认布局会更新；已有自定义大小、排序和设置保留，已移除的卡片不会重新出现。

**近期完成** 按明确填写的 `finishedAt` 日期统计每部作品一次，不用当前状态推断日期，也不代表阅读或游玩次数。点击月份查看按完成日期从新到旧排列的作品；标题打开作品详情，文件图标打开原笔记。列表保留完成日期和当前状态，更新、改名或删除笔记后同步刷新并保留所选月份；右上角可收起明细。卡片菜单的「统计口径」说明日期范围与排除规则。

在「全部作品」中，完成统计通过书、胶片、手柄图标分别查看图书、影视、游戏，不把三者合成总数。切换只影响这张统计卡片；左右键可切换类别，页面作品列表不变。各分类页面直接跟随自己的类型，不再显示重复切换。音乐的新页面默认提供作品浏览和作品分布，不默认添加完成统计；已保存或主动添加的统计卡片继续保留，明确填写的音乐完成日期可在该页面的统计卡中查看，但不代表播放次数或聆听时长。

**近期完成** 使用共用统计入口中的月度图，按明确记录的 `finishedAt: YYYY-MM-DD` 展示最近 3、6 或 12 个月。「… → 卡片设置 → 图表样式」可选择点阵或柱形，预览与应用使用同一批作品。默认点阵以小方块累计数量，图下标明每格对应的作品数；较大数量自动合并，尾数部分填充，浅色空格不代表完成记录。月份从左到右排列，空月份保留位置；只标当前查看月份和最高值，连续并列最高只标一次。鼠标悬停查看数值，点击月份展开作品；键盘左右键选择月份，Home／End 到首末月份，回车展开。卡片变窄时减少月份标签并收紧点阵间距，仍保留每个月的操作。不从“已读”等状态、页数或感受笔记推算完成日期和体验量。统计卡片可通过通用卡片菜单调整、复制或移出；留空的作品目录跟随藏馆设置。

**作品分布** 默认可见，也可从 **页面设置 → 添加本页卡片 → 作品分布** 添加其他实例。横向条形展示现有类型或标签的作品数量，点击分类查看对应作品及原笔记；长名称在条形上方换行，数量保持靠右。默认显示前六类，可展开全部分类。它统计当前目录和子页面类别中的全部收藏，不受完成日期限制。现有藏馆中首次补入尚未提供的分布卡片，保留已有实例；主动清空或全部隐藏的页面不自动填充。

在 **… → 卡片设置** 中选择类型（`genre` 文本或文本列表）或标签，可为标签设置前缀，例如 `topic`。作品身份标签如 `book` 不计入主题分布，前缀按完整层级匹配。一部作品在同一分类中只计一次，可以属于多个分类，因此各分类数量不能当作互斥占比或喜爱程度。未分类和格式异常分别保留「未分类」「需检查」入口；从展开列表打开原笔记修正后，图表和列表同步刷新。配置留空的作品目录跟随藏馆。添加分类时直接维护作品笔记的属性或标签，不生成另一份分类记录。

#### 主页快捷入口

主页的 **快捷入口** 初次放在 MOC 上方，之后可拖动布局，重启不会重置位置。点击右上角 **＋**，搜索并选择作品、普通笔记、Base、Canvas 或 Noria 页面，也可直接粘贴网页或支持的应用链接。默认显示封面／图标与名称，不常驻路径、类型和说明。入口菜单可以修改显示名称、图样和打开位置，也可前移、后移或移出；支持拖动排序。修改显示名称不会重命名原文件，移出不会删除原内容。

作品详情中的 **添加到快捷入口** 使用同一列表；主页作品封面优先打开已关联的作品入口，没有时打开作品详情，笔记按钮进入相关笔记。原主页书影音游入口会自动迁入并保留作品顺序，独立藏馆与统计继续保留。页数、日期与任务不是添加条件。链接只在点击时打开，不自动运行。

本节功能处于开发版本；已有隔离测试和代表性原生操作检查，真实收藏、跨主题及完整用户验收仍待完成。

### 作品列表卡片

这是可选的独立卡片，与藏馆中的“作品”卡片不同。普通浏览使用顶部藏馆即可；需要在其他页面直接打开原笔记时，再添加此卡。

选择 **页面设置 → 添加本页卡片 → 作品列表**（原“书影音游”卡片），指定作品目录后应用，默认包含子目录。识别规则与藏馆相同，包含上述中文身份标签及作品笔记的 `book`、`movie`／`tv`／`anime`、`music`／`album`／`song` 或 `game` 标签；名称以“清单-”“模板-”开头的笔记不列作作品。默认状态筛选值为“进行中”；在卡片设置中填自己笔记使用的状态，留空则显示全部作品。

可搜索名称、作者或导演，按类型与原有状态筛选，点击作品打开原笔记。打开来源保留卡片筛选；笔记属性改变后自动刷新。卡片设置可选封面或紧凑列表，封面支持库内图片及已有 HTTP(S) 链接，沿用 `image` 优先于 `cover` 的顺序；缺图仍显示标题与类别图标。图书页数表示当前读到哪里，不代表阅读量；不推断评分和体验日期。点击状态或页数可编辑当前状态及图书当前页，点击保存后写回原笔记；若状态或页数已在别处修改，需重新打开编辑。配置预览保持只读。

## 3. 任务看板

任务看板把日记、项目和普通笔记中的 Markdown 任务组织成四种互补视图。任务始终保留在来源文件中。

### 3.1 月视图

用于观察月度任务分布、跨日任务、截止位置和一段时间内的工作密度。适合先看整体，再进入周或日视图安排时段。

任务多时，在对应周内上下滚动；同周任务一起移动，日期标题保持可见，跨日条连续显示。其他周不受影响。编辑或完成任务后保留查看位置；完成状态通过勾选与颜色标记表达，标题仍清晰可读。

月表默认不显示带`#timeline`或`#tl`（含子标签）的时间轴事件，日／周表仍显示。右上统计入口说明当前规则；展开可查看标签、取消项与逾期结转条件，点击 **筛选设置** 进入原设置修改。返回后任务与数量同步更新。

![任务看板月视图](../assets/zh-CN/task-board-month.png)

### 3.2 周视图

用于安排一周内的任务和时间段。并列任务会根据列宽和高度自适应标题与时间信息，空间不足时优先保留任务辨识度。

同时段任务过多时，超出列宽的任务集中在附近的 **＋N**。点击可查看完整名称和时间，再打开原任务编辑；缩放窗口时列表随计数更新。收起的任务仍计入统计，不改变原笔记或安排。

拥挤日期的列头显示展开按钮，可进入那一天的日视图查看和调整；其他日期悬停或键盘聚焦时显示。日期文字仍打开日记。切换日／周视图保留正在看的日期；回到当前日期使用“今天”。

日／周表可通过 **活跃** 设置开始、结束时间，或切换全天。网格上方直接显示前后时段的任务摘要，窄列显示数量；点击摘要查看和编辑原任务，点击左侧箭头统一展开或收起。收起时，空日期不显示入口；整页没有此类任务时不占一行。改变显示范围不会改变任务时间、来源或统计。

![任务看板周视图](../assets/zh-CN/task-board-week.png)

### 3.3 日视图

用于安排当天的具体时间。无时段任务和全天事项保持在顶部，具体时间任务进入小时网格。

![任务看板日视图](../assets/zh-CN/task-board-day.png)

### 3.4 四象限

用于在任务较多时重新判断重要性和紧迫性。四个区域是同一任务池的不同组织方式，不会复制任务。

在顶部工具栏选择日／周／月／年；分区标题旁的数量跟随当前筛选。打开统计入口，选择“计划”等类别筛选，再选一次清除；切换周期保留筛选。筛选列表支持上下箭头移动、Enter或空格选择，Esc关闭并返回入口。拖动任务到另一分区只调整象限，不移动原笔记或改写日期。

![任务看板四象限](../assets/zh-CN/task-board-quadrant.png)

### 3.5 编辑任务

月表拖动改期会保留任务原有的日期字段和时刻：仅截止日期不会自动补成时段。周／日表移动保持真实时长；短任务的显示高度不代表时长。拖动超过小幅移动阈值后才开始改期，按 Esc 或在有效日期格外松手可取消。

改期保留原笔记中的任务、子任务和附注，不创建目标日期的日记。无日期的日记任务首次拖动后补充 `scheduled` 日期，不补造开始与结束时刻；月表按新日期显示，打开来源仍回到原笔记。日记卡片也不会因为任务仍写在旧日记中，就提前显示未来的安排。

周／日表的时段在空间足够时显示为一行，例如 `09:00–11:30`；窄卡可分两行。空间不足时只显示开始时间或隐藏角标，完整时间仍可在任务提示和编辑器中查看。

悬停任务条可查看原生提示中的完整标题和真实时间范围。跨日任务显示完整起止日期，不把当天网格的 `24:00` 当作任务截止时间；开始拖动时收起阅读提示。

拖动时浮层显示拟保存的时间，靠近可滚动区域上下边缘会自动滚动。月表范围条的真实首尾提供拖动把手，只调整对应日期，保留原时刻；跨周中间段不提供端点把手。单次任务改期后会短暂显示“撤销”（约 12 秒，停留或聚焦时延长），日记任务同样适用，仅恢复该任务行；任务又被修改时会提示冲突，不覆盖新内容。批量编辑暂不提供此撤销入口。

任务编辑器支持：

- 标题和标签；
- 优先级与状态；
- `start`、`scheduled`、`due`、`completion` 等日期；
- 开始和结束时间；
- 循环关系和前后依赖；
- 打开来源、保存和删除。

在任意 Markdown 笔记中，也可以把光标放在任务或普通文本行上，运行 **Noria: Edit or create task at cursor**。

主页、日记、看板和时间轴使用同一个编辑器。开始、计划、截止日期固定排列，年／月／日和时／分分别留出数字位置；直接输入时间不会弹出选择器，需要时点击时钟或按 `Alt+↓`。重复、依赖和生命周期日期按需展开。日期与时间可以留空；仅修改标题不会补日期，也不会自动移动另一端日期。保存后应用修改，关闭会在本次会话中保留输入，**放弃修改**才清除。

### 3.6 创建周期笔记

点击日期进入工作台的对应日记，首次保存才创建缺失的笔记。目标目录和模板来自当前路径配置。季度笔记以及关闭主页模块时的原生笔记入口，沿用日历的创建确认设置。

### 4.1 主编辑区与侧边栏

- 主编辑区适合较长时间范围、图层筛选和批量观察。
- 侧边栏适合常驻查看当前节奏，标题会根据可用纵向空间自适应排列。

时间轴在 Obsidian 恢复工作区后应直接加载，不应要求先打开任务看板。

### 4.2 导航与尺度

工具栏用一个按钮切换横竖。竖版按日期与真实时间混排任务、闪念和日记记录；“今日”定位到今天，向上、向下滚动继续浏览其他日期，接近边缘时按需补读。日期标题可打开侧栏日历跳转当前时间轴，不改变日记页的选择。今天没有内容时仍保留落点。横版尺度与竖版阅读位置分别保持。

勾选与编辑写回原任务，完成后原位弱化；竖版筛选可隐藏已完成，或进入“未安排任务”。目录／标签小字可选，未记具体时刻时不额外显示占位文字。笔记创建与最后修改默认关闭；最后修改不代表完整编辑历史。读取失败可在对应边缘重试，保留已显示内容；单日密集条目可继续展开。

长记录默认显示简短预览，点击“展开全文”原位阅读完整 Markdown；收起后仍能看到该条预览。展开状态随视图保存，不修改源笔记。勾选任务和刷新列表时保留仍存在的键盘操作焦点，不抢走其他面板的焦点；展开失败保留预览，可直接重试。

竖版从 **筛选 → 查看未安排任务** 打开未明确日期的任务列表。进入时从顶部开始，刷新保留列表位置；点击 **返回时间轴** 回到原阅读位置。任务仍在原笔记中，可点击标题编辑；此入口尚不支持直接拖入日／周表时段。

横版通过 **筛选 → 显示范围** 查看当前跨度并选择常用项；展开“自定义时长”可输入小时／天／周／月／年，只有点“存为常用”才加入快捷项。通过面板右上编辑图标排序、移除常用项；编辑时的“补回默认项”保留自定义项。自定义跨度保留数量，如“12小时”。边缘箭头按所选跨度移动，月／年按日历计算。改变窗口大小、刷新与重开保留范围，横竖切换不改写横版尺度。Ctrl/Cmd＋滚轮偏离精确值后显示“自定”和实际跨度。命名视图也保存精确起止。

- 点击**今天**回到当前日期。
- 普通滚轮横向平移时间。
- 拖动空白时间带进行平移。
- `Ctrl/Cmd + 滚轮` 缩放。
- 拖动底部日期行或缩略图均可平移；聚焦该区域后，方向键平移，`+` / `-` 缩放。

日期与缩略图共用一个连续的底部区域，只保留一排日期。小时尺度下，仅首处刻度和跨日位置补充日期；缩略图中较亮的片段表示当前可见范围。

![同一组示例任务的小时尺度](../assets/zh-CN/task-timeline-hours.png)

### 4.3 任务视觉与写回

默认自由排布中，不同项目的任务保持混排。圆点与短标题标识任务，额外详情在交互时出现：

- 所有任务统一显示圆点与其后的短标题，按开始时间定位；开始时间早于窗口的任务停靠左沿；
- 悬停或聚焦后显示完整时间、持续轨线与来源详情，区间手柄只在交互时出现；
- 圆点颜色表达完成状态，已完成标题保持与未完成标题相同的颜色和字重；
- 空间足够时尽量显示完整标题，冲突时再截断；
- 点击标题或圆点定位到 Markdown 中的原任务；
- 拖动任务或区间边界会写回原任务行。

写回前会检查来源指纹；来源已经变化时拒绝覆盖。

通过 **筛选 → 按项目** 可切换为项目总览，展开后每个任务占一行。项目标题打开源笔记，任务名称就近显示并打开共用编辑器。只有当前日期范围内的任务占用行位；未安排任务归入项目标题旁的「未安排 n」，点击后选择任务编辑安排。灰色括线表示当前任务日期的覆盖范围，不是项目进度，也不替代项目明确的计划日期。圆点表示单个日期，菱形表示截止日期；拉远后很短的时段保留小标记，悬停查看精确时间。短时段的点击区域更大，拖动端点仍对应真实起止时间。

展开项目后，如果安排都在当前视窗之外，标题旁会出现 **查看安排**，点击即可容纳该项目的实际日期，保留其他项目和筛选。箭头指向较早、较晚或两侧的安排；窄栏只显示箭头，悬停查看用途和日期。纯未安排项目保留未安排入口，不显示无效的展开或定位按钮。

主页项目卡的时间轴入口会限定当前项目并自动显示其任务日期范围；在筛选中取消项目条件，可返回全部项目。项目分组、筛选条件和展开状态可随已保存视图恢复。项目排布只展示任务；笔记活动、专注等其他图层使用自由排布。切换排布会保留当前项目条件；在自由排布中开启「专注」，即可同时查看该项目的任务安排和实际投入，保存视图也保留这个组合。未排期任务的专注同样继承能唯一对应的任务分类；包含／排除标签随之生效。点击专注仍打开记录所在日记，原文行号移动后优先按记录位置定位。取消项目条件可回到全部项目。项目标题与任务在同一时间画布中展开，不占左侧名称列。任务名称放在条内，短条名称就近放在上方；日期概览保持普通横轴的位置，拖动仍写回原任务，不改变独立截止要求。

### 4.4 图层与筛选

筛选中的「项目」可直接选择一个项目或返回全部项目；切换后会展开所选项目并定位已有安排，未安排任务从项目标题旁的数量入口选择并编辑。「显示范围 → 显示全部安排」可从移远的时间窗口返回当前筛选下的任务日期；没有已安排任务时禁用。常用天／周／月放在同一行，编辑常用尺度时再显示排序、移除和补回默认项。

横版可以选择任务、标记、笔记、Git、Noria 和番茄钟等图层。番茄钟默认关闭。

筛选支持：

- 显示或隐藏完成任务；
- 文本查询；
- 仅显示指定标签；
- 排除指定标签。

筛选只改变观察方式，不修改任务。

横竖版的任务搜索使用相同条件：`tag:#标签`、`path:目录`、`status:open`／`status:done`，可用 `-tag:`、`-status:` 排除，并与普通文字组合；未安排任务同样适用。竖版记录可按正文与 `path:` 查找，任务状态条件不会把记录当作待办。两种方向的筛选设置目前分别保留，切换方向不会自动复制。

### 4.5 命名视图

横竖版均从 **… → 保存与管理视图** 保存当前查看方式；筛选只承接内容、显示范围和排布。横版保存图层、完成状态、查询、包含／排除标签、时间范围与缩放；竖版保存任务／记录／笔记活动开关、完成状态、查询及任务来源显示方式，继续浏览当前日期。

选择视图会切到它保存的方向并恢复条件；旧视图按横版承接。条件变化后显示“已修改”，只有点击“更新”才覆盖原视图。保存失败保留输入与原视图，可直接重试。重命名不改变条件，删除视图不清除当前筛选或源记录。普通横版筛选和所选视图也随 Obsidian 工作区恢复。

### 4.6 时间标注

1. 从横版自由排布的 **… → 框选标注** 进入标注模式，在主区域空白处拖动以预览时间范围，也可以按住 `Shift` 拖动。
2. 填写名称，选择已在主页登记的项目或**全局时段**，调整时间与颜色。
3. 点击**保存**保留标注，点击**取消**或按 **Escape** 放弃草稿；随后恢复普通平移。

标注以紧凑阶段带显示在混排任务上方，项目标注显示为**项目名 · 阶段名**。重叠时最多显示两行，其余可通过**更多阶段**打开。点击阶段名称可编辑或删除；编辑期间拖动端点只改变草稿，点击**保存**才保留，按 **Escape** 取消。标注不会修改任务日期，也不代表新增任务或已经投入的工时。

## 5. 日历与日记

工作台顶部提供常驻的**主页 / 日记**入口。日记正文和已确认复盘同页展示，复盘位于正文下方，目录可直达；共用当前周期、日期和 Markdown，参考材料按需打开。以下更新当前随本地体验包提供。

![日记工作区](../assets/zh-CN/diary-workspace.png)

点日期标题临时打开原有日历；选择**在侧栏打开**可保持日期导航。侧栏日历已显示时，日期标题直接使用它。任务看板、时间轴和普通笔记保留独立打开的方式。

### 5.1 主要操作

日／周／月／年统一使用“待办”卡。当前周期的前 3 项重点放在卡内顶部，其余待办在下；已完成默认显示前 3 项，可收起或展开更多。重点沿用任务优先级和日期排序，历史日期不推测当时的重点。勾选、编辑、拖入专注及来源打开仍操作原任务。

概览与待办、习惯可并排，记录和复盘在下。日、周、月、年分别有默认卡片组合；每篇笔记可以独立添加统计、调整卡片设置和布局。切换日期不会自动改变宽度或位置。

卡片定义、统计条件、尺寸、顺序和折叠状态都保存在 Noria 插件配置中，并按笔记路径关联；添加卡片不会创建日记文件，也不会向已有 `.md` 添加配置。笔记或文件夹改名时，配置随之迁移。正文、任务和专注记录仍保留在原笔记。

卡片窗口默认修改本篇，不再要求每次选择范围。顶部 **页面设置 → 默认卡片…** 修改同类日记的公共起点；**恢复默认布局** 清除本篇尺寸、顺序等设置，保留本篇添加的卡片及原文。内置待办、习惯、记录、复盘与扩展卡片遵循相同的本篇布局规则。

此前写入的 `noria-view / diary-cards` 块仍可读取，不自动批量改写历史笔记；首次修改卡片时配置转存插件设置，旧块原文保留。停止新增此类代码块。单独复制 `.md` 不携带 Noria 卡片设置；跨库保留这些设置需要迁移插件配置。普通 Markdown 模板仍负责正文和分节。

- 悬停卡片或将键盘焦点移入卡片，**…** 可调整宽度、移动或折叠；窄窗格会自动减列。所有布局操作都保存到当前笔记的插件配置。
- 日、周、月、年按钮围绕所选日期切换周期。下方短日期条分别展示选定周的七天、相邻周、当年月份或相邻年份；日期标题仍可打开日历。
- 侧栏日历点击月／年标题打开列表，点月份直接进入对应月记，点年份直接进入对应年记；列表保留，方便连续查看。顶部中间仅有“返回日历”图标，且只在列表展开时显示；点击它、再次点击同一标题或按 Esc 返回日期网格，不改变当前日记。日期输入弹层仍按年→月→日选择，不跳转日记。
- **今日 / 本周 / 本月 / 本年**回到真实当前周期。选定日期后收起临时日历，并恢复键盘焦点。
- 日期前后箭头与任务面板使用同款控件。铅笔/书本图标以及 Obsidian 阅读/编辑切换命令、当前快捷键均可切换模式。列表、文件和刷新图标分别进入目录、源笔记和重新读取；悬停或聚焦可查看说明。
- 已有笔记先阅读；缺失日期显示配置中的模板，可直接书写。改动自动保存，保留编辑器、选择与滚动位置；`Ctrl/Cmd+S` 可立即保存。
- 切换页面、日期或正文／复盘编辑位置时先保存；保存冲突会保留草稿。关闭后可恢复未提交的正文及目标日期。

### 5.2 创建行为



待办卡右上角的 **＋** 打开共用任务编辑器，保存到当前所选日／周／月／年笔记。日记中的新任务预选所选日期为计划日期，开始与截止日期保持空白；关闭保留本次会话的输入，放弃修改才清除草稿。

浏览、聚焦或离开未经修改的模板不创建文件。首次文字改动会自动保存到所选日期；先打卡或快速记录，也会使用同一配置模板创建。缺失文件的源笔记图标可以按日历创建设置明确建档并打开原文。切换日期或阅读模式时，会将待保存输入写回原目标。已有空文件或只有属性的文件保持现状，不会自动套回模板。

新的内置日、周、月、年模板从**记录、计划**开始，Inbox、习惯记录和复盘在使用时加入。既有自定义模板保持，日期变量使用所选周期，补写过去记录也如此。可以增删或重排标题。`cssclasses: [daily-clean]` 限定日期笔记的排版，继承主题与字体。行动区聚合原有来源中的当期任务和此前未完成任务；点击标题打开共用的紧凑编辑面板，其中的源笔记图标定位到原任务行；勾选框完成或重开原任务。动态三件事只在真实当前周期出现。正文预览中的 Markdown 复选框仍只读。

日记与主页的习惯操作写入配置中的当天笔记；定义留在 Habits.md，数值型记录保存实际值与当时目标。过去日期展示已有记录并提供明确补录，未来日期不能打卡。记录习惯也会创建尚不存在的日记。周、月、年显示任务、打卡和字数概览，需要时通过页面加号添加独立统计卡片。

通过**添加卡片 → 活动记录**，可以按日期浏览日记、闪念和任务创建／完成动态。日记中当前正文已展示的来源不会再次完整展示，复盘默认位于记录之后，可自行移动。活动卡按 7、14 或 30 个日期分批加载，点击来源按钮或事件标题打开原笔记；记录仍由源笔记保存。

卡片设置可分别开关记录、任务动态、笔记创建和最后修改。任务仅采用明确记载的创建／完成日期，不把计划日期推算为实际发生日期。笔记创建和最后修改默认关闭；最后修改只反映文件当前时间戳，并非逐次编辑历史。主页使用本周范围，日记中跟随所选周期。

正文编辑中也可以勾选任务或记录习惯。与正文改动互不重叠的记录会接续到草稿，原处也有修改时仍需核对。习惯原行中的备注、标签和块链接会保留；目录在阅读和编辑中均可按当前标题跳转。

保存失败或原文在外部改变时，编辑器保留输入，就近提供重试、复制和恢复动作。重新打开的恢复正文先供检查，继续编辑或选择**使用这份草稿**后才恢复保存，不能仅因打开便覆盖原文。复盘沿用相同保护，详见[保存保护](#85-保存保护)。

安装不重写已有模板、旧视图块或历史笔记。旧 `focusPanel`、`habitCheckin` 习惯入口也写入对应日期笔记，支持撤回和实际数值；没有明确日期时不打卡。原清单中的旧打卡继续可读，同一习惯同一天的日期笔记记录优先，包括撤回。历史迁移需先查看具体差异，重复记录保留原文核对。季度笔记与关闭主页模块后的原生入口，继续按日历设置创建和确认。

日期预设在阅读与 Live Preview 中使用一致的标题层级。插件内维护这份样式；若原库另启用了旧版 `daily-clean` CSS 片段，可在外观设置中停用该片段后使用插件预设，片段文件可以保留。

### 5.3 日期来源

日历支持三种来源：

- **Noria**：使用“总览 → 路径”中的 Diary root 与模板。
- **Daily Notes**：读取 Obsidian Daily Notes 配置。
- **Custom**：单独指定目录、命名格式和模板。

界面只显示当前来源需要的字段，避免同时出现多套互相竞争的目录设置。

### 5.4 随手记与日态

日记的**记录**页中，方框铅笔图标打开所选日的随手记。主页捕捉与 **Noria：随手记**命令写今天，可在 Obsidian 中自行分配快捷键。输入区明确显示目标日期；周、月、年页不会悄悄写入某天日记。

回车换行，`Ctrl/Cmd+回车`保存。链接、段落与缩进保留在 Markdown 的 `## Inbox` 下。今天的记录附上时间；补写过去或未来日期时不自动虚构发生时刻，可以自行写明 `[HH:mm]`。阅读时用简洁的时间列呈现，有时间的记录在前、未标时间的在后，不重排源文件。

首次记录使用所选日配置的模板。切换日期保留未写完的输入；保存失败保留文字供重试。正文的独立改动继续保留，尚未解决的冲突会阻止追加。记录本身不会创建任务，需要时再选中文字主动采纳。

每日正文旁的心情、精力使用原生菜单，清除即取消该值；专注可从 **…** 按需填写，已有天气只作背景。向空白日期填写日态，同样采用该日的模板。

### 5.5 日记模板与卡片布局

日记的周期栏 **… → 编辑模板** 打开当前日／周／月／年实际使用的模板文件；**更换模板** 直接定位到对应来源的设置：Noria 模板、自定义周期模板，或 Obsidian 日记插件。Noria 的模板输入框可搜索整个库的 Markdown 文件。更换模板只影响新建笔记；选了空白模板就从空白开始，选定文件缺失或无法读取时提示修复并停止新建。已有日记仍可记录和修改状态，不依赖模板继续存在；只有未指定模板时才使用内置初始内容。

日记的日／周／月／年按钮行右侧提供 **添加卡片、源笔记、页面更多**。添加统计卡片使用共用卡片库，默认跟随所选周期。记录、复盘和添加的卡片可从标题空白处拖动排序，边缘调整宽高；记录／复盘菜单的「布局」也可调整位置。移出卡片保留源内容，从卡片库恢复。四种周期各自保存布局。日期汇集建议放在最后，正文嵌入也放在记录与复盘之后，避免重复显示。

### 日记中的日期笔记

日期笔记保留在所属目录，文件名使用 `YYYY-MM-DD 标题.md`，需要区分同日记录时可加 `HHmm`。一份共用 Base 可放进需要的日、周、月、年笔记正文，也可作为 Noria 日记中的卡片。经常使用时，将嵌入语句放进自己选用的周期模板；Noria 不自动追加列表，也不改写已有日记或模板。

将 [日期笔记 Base 模板](../templates/Dated%20notes.base) 复制到现有模板目录，可改名为 `日期笔记.base`。正文使用 `![[日期笔记.base]]`：默认“Records／记录”视图按所在文件名开头的 `YYYY-MM-DD`、`YYYY-Www`、`YYYY-MM` 或 `YYYY` 筛选，可在周期后加空格和标题。周从周一开始，使用 ISO 周年与周编号，跨年周会包含另一公历年的相应日期。无法识别的笔记名显示空结果，不跳到今天；独立打开 Base 则显示全部记录。“All／全部”保留表格供自行筛选和调整。原生列表保留标题、可选时间和日期分组，点击打开原文；查询不依赖修改时间，也不提取正文演进条目。

在 Noria 日记中打开 **页面设置 → 添加本页卡片 → 笔记与 Base**，选择同一份 Base。卡片跟随页面所选日／周／月／年，即使尚未创建对应日记也能查看；不会为查询生成空日记。卡片内隐藏重复工具栏，当天不重复日期分组；通过卡片 **… → 管理内容** 打开原 Base 调整筛选、列、排序和样式，修改后卡片同步更新。周期只在内存中绑定，不覆盖共用查询文件；日、周、月、年页面是否放置卡片仍由各自布局决定。上述周期绑定针对此模板，其他 Base 不会被改写查询。原生正文嵌入的自定义文件名需自行调整 Base 规则；Noria 卡片直接使用所选周期。

## 6. 习惯

习惯系统把“今天是否完成”和“长期是否形成”分开呈现。

### 6.1 今日习惯

主页 Inbox 卡片下方可以显示今日习惯入口。这里负责快速打卡，不重复历史图表。

### 6.2 习惯卡片

完整习惯卡片显示习惯名称、日期列和打卡状态。习惯名称复用 MOC 卡片的标题字号与字重，保持全插件文字层级一致。

支持：

- 勾选型习惯；
- 数值型习惯；
- 目标值和单位；
- 新增、编辑、暂停和标记已养成；
- 从 `#tl/sleep` 刷新睡眠习惯。

### 6.3 历史与热力图

主页固定显示习惯名称和今天的操作列，近期日期格随卡片宽度适配。点击历史图标展开完整范围，不增加卡片高度；历史可横向滚动，刷新后保留展开状态与正在查看的位置。所选范围包含今天且只显示一次，默认 21 天，**… → 卡片设置 → 显示天数**可改为 7、14、21、30、60、90 天。历史格可以补记，并明确显示目标日期。

每个习惯可选图样与颜色；名称下显示连续达标次数及本周实际打卡天数，悬停摘要可查看计划内完成／应做及额外打卡。连续数不受可见窗口限制。习惯设置可选择每天或指定星期，并指定新计划的生效日期。休息日和已记录的暂停区间不打断连续；休息日额外记录不增加按计划连续数。今天尚未结束时，未打卡不会提前算作中断。旧习惯没有计划信息时沿用每日规则，不推算过去的暂停区间。

新建习惯可以填写过去的“开始坚持日期”。补录早于首次计划时，本周实际打卡仍会计数，并提示补全历史计划；点击习惯名称进入设置，向前补全开始日期。此操作只扩展最初计划，不覆盖后续的计划变更或暂停记录，也不改动已有打卡原文。

主页和日记共用勾选、数值及时间控件。数值与目标分开；保存失败保留输入。定义归习惯清单，实际记录归对应日期的 Markdown。改名保留历史关联，暂停或已养成不删除记录；修改目标不重算过去的打卡。

数值目标可通过“新计划生效日期”安排调整。新建数值习惯从开始日期记录目标历史，后续调整按生效日期判断；补记使用该日目标，已有记录仍保留自己的目标。旧习惯第一次调整前的目标历史不会被自动补造；补记时若没有该日依据，输入框会出现“当日目标”，只保存到这一条记录。具有目标历史后，更换类型或单位应新建习惯，避免改变旧记录的含义。

数值习惯可显式选择一个日记记录属性作为来源，一次填写供打卡和统计共用。热力图与周期汇总继续单独提供。

## 7. 趋势和统计

趋势和统计用于观察持续变化，不用于每天评价自己。

### 7.1 共享时间范围

所有统计卡片共享一套范围控制：

- 最近 30 天；
- 周；
- 月；
- 年；
- 自选范围。

### 7.2 笔记趋势

笔记趋势统计新建笔记数量和当前日记的非空白字符数。字符数表示当前文件内容，不等同于当天新增字数。主页笔记／任务趋势支持鼠标或触点选择日期，也可用左右键、Home／End 查看悬浮提示中的完整读数；调整宽度保留所选位置。零值不绘制有高度的柱条。通用折线／柱图可点击所选日期原位编辑属性或查看来源，保存后的自动刷新保留所选日期。

点击内置趋势图中的日期位置，或用方向键选中后按 Enter，可查看该日期的来源。笔记趋势分别列出新建笔记和日记字符来源；任务趋势分别列出已完成、未完成任务，两组之和为活动总量。点击来源打开原文，任务定位到当前所在行；返回后保留图表所选位置。

### 7.3 任务完成趋势

显示任务活动总量、完成量和完成率。没有完成日期的已完成任务保留在“无日期完成”中，不强行放入某一天。

### 7.4 习惯与工作量热力图

- 习惯热力图可以选择具体习惯或查看汇总。
- 工作量热力图把笔记、任务和字数等活动规范化为相对强度，不是精确工时。
- 任务指标按已配置任务范围和实际完成日期统计；旧「打开日记统计」入口的热力图也采用此口径，标题为「完成任务热力图」。未完成及没有完成日期的任务不填入某一天。数据读取失败时显示错误，不替换为日记复选框数量。

### 7.5 笔记占比

笔记占比按知识库顶层目录统计，不按标签统计。它用于观察内容长期分布，而不是评价目录多少。

### 7.6 日常记录

日态字段未填写时只显示图标与名称；分类选择提供状态图样，等级使用可点选的分段表达。**设置记录项目 → 编辑 → 状态外观**可分别修改状态的显示名称、图标和颜色，笔记中保存的原选项值保持不变。属性、数据类型、单位或等级范围不同，应创建独立字段，避免重新解释旧记录。

心情和精力是可关闭、改名的预设。日记中的 **… → 记录项目**可以选预设、复用已有属性或新建项目，配置选项、等级、数值 / 单位或开关，以及图标和颜色。默认每天保存一个当前值，数值可直接修改或累加。

需要保留每次记录时，在该项目中启用「日内多次记录」。数值项目可选当日合计或最近一次，状态项目使用最近一次；它表示最后一次记录的状态，不代表全天感受。点开项目即可新增，点明细可修改，右侧删除只移除该条。时间可留空，补记历史日期不自动填时间；开启时原日值保留为无时间记录，不拆分、不补造时间。

日记记录采用按字段配色的紧凑按钮；点选后直接保存。主页“日常记录”对齐展示最多三项的日期变化：分类用色带，数值用独立刻度的趋势线。未记录保留空缺，不当作零。标题栏显示所选日期，点击可选日或回到今天；范围包含今天时默认选中今天。左侧名称与数值可直接编辑所选日，图上悬停或左右键浏览日期，点击或回车也可编辑，保存后保留所选日期。标题栏的筛选图标选择显示项目，“汇总与来源”按需查看分布、均值与原始记录。

单次记录保存在日期 Markdown 的原生属性中。多次记录保存在当日日记的对应分节，属性是由明细生成的日摘要，供 Base 读取。统计和习惯绑定读取同一份明细；周期均值按每天的摘要计算，不因某天记录次数多而增加权重。已有明细日期保留当时的汇总方式，关闭多次后仍可查看和编辑。手工调整明细后，Noria 按明细读取，属性摘要在下次通过 Noria 保存时更新；不要另改属性来替代明细。

停用不删除历史；改变显示名称不重命名属性。若单位或类型改变，应新建项目，避免改变旧值含义。复盘材料会带入对应周期已配置记录的名称、单位和值，日记正文保留明细。

卡片的「选择显示项目 → 管理项目」和「… → 管理内容」进入同一记录项目列表。停用已选项目后，卡片保留原选择，不自动替换成其他项目；重新启用会恢复显示，原有统计仍可读取历史值。空卡可直接选择项目，全部停用时可进入管理。日记卡的选择按日／周／月／年布局分别保存；从记录入口添加统计卡会留在当前页面。

![自定义记录与统计](../assets/zh-CN/daily-state.png)

### 7.7 自定义统计卡

“添加卡片”或“统计模板”中的 **概览** 可在同一卡片展示专注、任务、习惯与码字分布，默认整行宽度。卡片设置中的第1–6行可选择、隐藏或调整指标顺序，也可加入笔记数及已配置的数值型日常记录。放在日记中默认跟随所选日／周／月／年；悬停或左右键选择日期，各行同步显示数值，点击或回车查看来源。日视图仅为实际专注显示时段，其余项目按真实记录显示，不推测发生时刻。码字数表示对应日记的当前非空白字符，不是历史编辑增量。已有页面不会自动加入或替换卡片。

通用统计的配置预览只读：可选择日期、查看读数与来源，不在预览中填写或修改记录。需要修改时，从正式卡片或原笔记操作；取消配置不保存卡片草稿。

预览中的来源在明细窗口内阅读，属性按需展开，任务复选框保持只读；“返回来源”回到列表，关闭明细回到未应用的设置，保留草稿与编辑位置。正式卡片的来源仍直接打开原笔记。

从记录项目选择“添加统计卡”，会带入属性；也可从卡片库选择“统计”，使用记录、文件夹构成、任务或习惯模板。按“数据来源 → 字段与计算 → 时间范围 → 展示样式”配置，旁边预览真实结果；匹配数和来源从图表右上角打开。更多筛选中可设置子目录、标签、属性条件及分组。

来源列表中的任务显示标题、日期和来源路径，点击后收起列表并定位到原文中的任务行；插入其他段落不会使定位沿用旧行号。任务已改动或无法唯一匹配时，列表提示刷新统计。普通笔记复用已打开的标签，缺失来源不会新建空笔记。

支持数量、合计、均值、极值与分类分布，以及任务完成、习惯打卡。日记卡默认跟随当前周期，主页默认跟随共享范围，也可选择固定范围或不限时间。普通笔记的日期趋势必须明确使用事件日期属性或文件创建 / 修改日期；当前状态不能冒充历史变化。

按数据类型可选数字、折线、柱图、横向条形、环图、连续色带、按日状态格、日历热力图、目标进度和前期对比。重叠分类或负值不能显示为环图占比；任务完成比例以所选截止／计划日期范围的全部任务为分母，反映这些任务的当前完成状态。习惯完成比例以历史计划中截至今天应打卡的次数为分母。目标进度必须设置同单位目标；前期对比使用等长日期区间，本期尚未结束时只比较已过去的天数，前期为零时不计算增长百分比。 前期为零或缺少记录时会直接说明；有负值的对比使用共同零线，负值向左、正值向右。数字摘要保留完整数值，单位以较小文字显示；点击数值或前期／本期可查看对应来源。没有应打卡次数不显示为 0% 完成；超出目标时保留实际百分比，进度条最多填满。

缺失值与明确的零、否分开处理，折线不会跨过缺失日期。类型或指定单位属性混杂时列出不能计算的来源。多选项按每个选项去重计数。点击日态日期或属性图表的单条来源可就地编辑，多来源先选择笔记；实际修改写回对应来源，原值在别处变化时会提示重新打开。日记缺失日期可直接补记，未来日期不填写实际记录。数字汇总和任务／习惯图表打开来源，不把聚合值写回某一条记录。

## 8. 复盘中心

日、周、月、年回顾位于**日记下方的复盘区域**，也可从正文目录直达。正文与复盘共用当前日期和 Markdown；既有复盘命令仍能直接定位所需周期。预览显示已确认结果，恢复草稿与参考材料单独处理。本节更新随本地体验包提供，尚未正式发布。

![复盘中心](../assets/zh-CN/review-center.png)

*配图使用示例内容。*

### 8.1 基本流程

1. 选择周期和目标日期。
2. 已有复盘先阅读，还没写的周期直接开始书写。
3. 点击分区旁的铅笔编辑这部分，或用**编辑全文**修改整篇 Markdown；两种方式处理同一份草稿。
4. 需要原始记录、下级复盘、证据或外部分析时打开**参考**。
5. 改动自动写回当前日期笔记，并保持编辑状态；切换参考日期不会改变这个保存目标。

### 8.2 阅读与编辑

分区跟随 Markdown 的真实标题层级与顺序，自定义标题和重复标题均可保留。短内容直接完整显示，长内容才提供**展开阅读**。宽栏最多让相邻两个短分区并排，窄栏使用一列；目录图标打开章节菜单，旁边保留源笔记、重新读取和参考图标，悬停或聚焦可查看说明。

编辑使用 Obsidian 的 Markdown 源码模式，支持标题、列表、链接、撤销/重做和 `Ctrl/Cmd+S` 立即保存。自动保存保留编辑器与光标，中文输入法完成组词后才写入。编辑一部分时，其余正文保持不动。**全部分区**和书本图标会处理待保存输入后返回阅读，也可使用 Obsidian 阅读/编辑切换命令及当前快捷键。普通误改使用撤销；需要修改复盘外层标题时，进入全文编辑。

**添加写作提纲**按需使用。可以改名、增删章节，只写几句连贯记录，也可以自行保留 GDD 作为反思提纲；不再要求固定填写亮点、偏差和阻塞。安装不会重写已有模板或历史笔记，自定义模板仍由你决定。心情、天气、能量和专注继续属于独立日态数据。

### 8.3 跨周期查阅参考

**参考 → 记录**在宽栏与正文并排，窄栏临时占用阅读区域；关闭后回到原编辑器和光标位置。

月复盘可以查看周回顾，再用**追溯原始记录**进入对应日记；年复盘可以参考月份或具体记录。缺少下级复盘时，仍可查看已有记录并继续写。日期沿用现有日记与日历路径。查看当天记录时，参考预览会略去当前正在处理的复盘，避免重复展示。

复盘预览中的任务只读，需要修改时打开源笔记。旧嵌入视图和笔记嵌入改为来源链接，避免片段中的控件按错误行号写入；普通图片仍可显示。

### 8.4 Evidence 与外部 Agent

“参考 → 分析”保留独立分析。资料变化或缺少资料版本时，会显示核对提示；“准备材料”重新读取当前记录并更新材料与提示，不生成新分析，也不改已有复盘。失败时保留原分析，可直接重试。

开发版本通过内置 MCP 提供复盘读取、材料准备和分析提交（`reviews.read`、`reviews.prepare`、`reviews.submitAnalysis`）。外部助手可把分析保存到独立文件，Noria 刷新显示；你可在“参考 → 分析”中选择段落加入复盘，原有内容保留。资料或分析已变化时，提交会要求重新核对。接口详见[复盘 API](../AGENT-API.md#reviews-and-reading-material)；本批仍待安装测试构建及原生验收。

Noria 准备本地 evidence JSON 和提示词，不在插件内调用模型。从**参考 → 分析**准备证据，运行自己的外部流程后，再刷新检查其生成的复盘笔记。

提示词指向 `.material.json`，其中保留原文、相关任务与日态事实、来源索引。完整 evidence JSON 继续供具体疑点核查。月材料优先使用已采纳的周回顾，年材料优先使用月回顾；缺少下级复盘时使用日记。供模型阅读的材料省略可执行视图块与重复统计，保留作者文字。

默认 skill 按具体主题组织，区分事实与解释，允许生活记录止于体会；篇幅随内容伸缩，不固定 GDD 或最低字数。只有影响重要判断的明确缺口才补读，不要求扫描全库、全部对话或每个项目的三件套。

已有安装可在复盘设置的**默认复盘 Skill → 安装**更新未改动的旧默认版本。自定义 skill 会保留；**重置**才会明确覆盖它。插件仍不调用模型，也不自动采纳生成结果。

**加入这部分**将选中的分析章节采纳到复盘中，保留已有文字，并自动保存结果；仅打开或刷新分析不会写入正文。采纳不会创建任务。只留下你愿意纳入复盘的内容；观察、感受和生活记录不必都转成行动。

### 8.5 保存保护

- 未保存内容进入恢复草稿；
- 目标笔记在外部发生变化时阻止覆盖；
- 外部分析由你主动采纳后才进入正文；
- 本人编辑自动保存，重新打开恢复草稿本身不会写回 Markdown。

恢复草稿所依据的原文仍一致时，会先展示未保存文字供检查；继续编辑或选择**使用这份草稿**后恢复保存。原文变化、旧版本草稿无法安全核对，或同一周期另有未处理草稿时，通过**草稿（n）**选择查看、复制或使用；**舍弃这份草稿**只处理当前选中的一份。

保存发生冲突时，**保留草稿并重载原文**可以先保住本地内容，再载入最新原文进行整理。保存成功只清理本次已处理的草稿，其他窗口或尚未处理的内容继续保留。复盘的硬换行、缩进和代码围栏参与保存与冲突比较；日期和周期不一致的输入会被拒绝。

首次保存会用一对在阅读模式中隐藏的注释绑定完整复盘。编辑源文件时保留这两个标记，其中的标题可自由改名：

```markdown
%% noria:review:start %%
## 这个月的几件小事

### 值得记住的事

自己的文字。
%% noria:review:end %%
```

标记缺失、重复、旧复盘标题不唯一或代码围栏未闭合时，会阻止保存。通过**打开来源**修复原文后再刷新；复盘范围外的内容保持不动。

### 8.6 从记录或复盘采纳任务

阅读或编辑日记、复盘时，选中一段文字，用右键菜单或 **… → 从所选文字创建任务**，也可选择**关联到已有任务**。两个动作同时提供 Noria 命令，可在 Obsidian 中分配快捷键。

新建时，在同一任务编辑器中调整标题，通过**保存到**选择项目已有任务笔记或采纳当天的日常任务；日期可以留空。关联已有任务只补充出处，原任务的标题、状态和排期保持。所选文字本身已经是任务时，直接打开该原任务。

原文完整保留，任务下方用普通 Markdown 链接和引用保存出处。保存后继续原来的阅读或编辑；成功提示中的**查看任务**可以打开任务，任务编辑器中的**回看记录**图标返回对应日记或复盘。再次从同一段文字操作，会提供已有任务，并保留明确另建一条的选择。

关闭任务编辑器会在本次会话中保留输入，**放弃修改**才清除。记录的恢复稿或冲突、已经变化的原段落需要先处理；采纳动作不会代你确认恢复稿。

## 10. Markdown、数据与外部工作流

### 10.1 数据边界

| 层级 | 内容 | 定位 |
| --- | --- | --- |
| 内容层 | 笔记、任务、项目、日记、习惯、倒计时 | 以 Markdown 或 Base 为准 |
| 配置层 | 路径、模块、主页布局、视图偏好 | 插件 `data.json` |
| 派生层 | 统计快照、复盘 evidence | 可重新生成的辅助数据 |
| 恢复层 | 未保存复盘与保留的冲突草稿 | 人工输入，不能重新生成；仅在保存成功或明确舍弃对应内容后清理 |
| 凭据层 | 天气服务密钥 | Obsidian SecretStorage |

Noria 不会把知识库转换成私有数据库。停用插件后，普通 Markdown 内容仍可阅读和编辑。

### 10.2 任务

Noria 识别标准 Markdown 任务：

```markdown
- [ ] 整理论文实验结果 [start:: 2026-08-04] [due:: 2026-08-07]
- [x] 完成初稿 [completion:: 2026-08-03]
```

任务可以包含 `start`、`scheduled`、`due`、`completion`、`created`、`cancelled` 和优先级等信息。看板、时间轴和日历编辑同一来源行。

### 10.3 时间轴事件

带 `#tl/` 标签和时间字段的任务可以进入时间轴。事件模板保存在 `Event library.md`：

```markdown
- [x] 深度工作 [default_tag:: #tl/focus] [default_start:: 09:00] [default_duration_min:: 90] #tl/template
```

### 10.4 习惯、项目与倒计时

- `Habits.md` 维护进行中、暂停和已养成习惯。
- `#habit` 任务默认不混入普通待办。
- `Projects.md` 使用分组和 wikilink 维护项目入口。
- `Countdowns.md` 使用 Markdown 表格保存重要日期。
- `Inbox workflow.md` 说明使用方式，`Inbox queue.base` 提供文件与属性的可编辑视图；卡片和 Base 共用笔记中的 `inbox-work` 安排。
- 插件自动更新未改过的默认队列和说明；自定义或来源不明的内容保持原样，删除的文件不会自动重建。需要采用新版或恢复上次更新时，在 Inbox 工作流的高级设置打开“配套文件”。恢复后会保留你的选择，不再次自动覆盖；如果文件在更新后又被编辑过，则保留现状并提供备份详情。

### 10.5 日记与复盘

日、周、月、年笔记仍是普通 Markdown。日记与复盘读写同一份日期笔记，任务列表和统计由工作区提供。旧笔记和模板中的视图块仍可使用。

当前日期笔记发生文件变更时，干净的阅读内容自动更新，日期导航和卡片布局保持；未改动的编辑器保留选区。尚未保存、冲突、等待采用的恢复草稿及中文组词中的输入不会被外部刷新替换。并发修改仍按原有冲突和恢复流程处理。

在日记页面通过 **页面设置 → 添加本页卡片 → 日记章节**，填写卡片名称并选择二级标题。候选来自当前笔记与该周期已配置的模板，也可直接输入标题名；预览只显示该章节及其下级标题。应用后使用通用卡片菜单调整宽度、顺序、收起或移出。

配置按日／周／月／年分别共用，切换日期后读取对应日期笔记中的同名章节。卡片右上角铅笔在原笔记中打开该标题；若本期尚无笔记，点击后才按已有日记模板创建并打开。仅浏览和预览不创建文件。标题缺失、重名或内容为空时分别提示，不猜测替代章节。此卡片为阅读入口，正文复选框不在这里修改；编辑和任务操作仍使用原笔记或任务卡片。

**记录卡片 → … → 卡片设置 → 展示范围** 默认选择「整篇」，也可选择「指定章节」，勾选当前笔记或模板的二级标题，或添加其他标题。选中的章节按原文顺序显示，复盘和当日习惯记录仍由各自卡片承载。缺失或重名标题会提示，不自动显示其他章节。设置按日／周／月／年分别共用；只改变阅读展示，铅笔仍打开完整原文，正在编辑的内容和选区保留。新增独立章节卡片不会自动裁掉记录卡片中的同名内容，需要时自行选择展示范围。

### 10.6 外部内容进入主页

Markdown 简报来源使用：

```text
名称 | 路径 | 角色 | 新鲜度小时数
```

例如：

```text
每日简报 | Noria/Inbox/daily-brief.md | daily | 36
当前建议 | Noria/Inbox/current-suggestions.md | current | 72
```

可用角色包括 `daily`、`current`、`weekly`、`project` 和普通笔记。

### 10.7 外部 Agent 协作

1. 外部 Agent 读取指定 Markdown、复盘 evidence 或 Noria JSON 导出。
2. Agent 把简报、建议、项目监控或复盘结果写入约定文件。
3. Noria 展示这些内容并保留来源跳转。
4. 涉及日记和复盘正文时，由用户确认后写回。

### 10.8 安全边界

- 自定义 JavaScript view 默认关闭；
- 只运行显式信任的库内相对路径；
- 禁止协议地址、绝对路径和路径穿越；
- Noria 不静默移动笔记、重组目录或改写无关正文。

## 11. 常用工作流

Noria 不要求每天完整使用所有模块。

### 11.1 开始一天

1. 打开主页查看“继续推进”和当前项目。
2. 在待办卡片中选择当前节奏下适合处理的任务。
3. 查看今天的习惯和临近倒计时。
4. 需要安排具体时段时，再进入任务时间轴或日历。

### 11.2 随手捕捉

- **Noria：随手记**命令写今天；日记中的随手记图标写当前所选日。Timeline 中也可使用随手记输入。
- 已经明确可执行的事项使用“任务”。

### 11.3 处理 Inbox

先收下内容，有空时直接阅读和整理，不要求填写处理阶段。点击标题打开原笔记，已打开的笔记复用标签；回到 Inbox 保留筛选与阅读位置。长列表在卡片内滚动，不必拉长卡片。

- 按住条目展开两侧动作，拖到目标后松手保存；也可点击已有标记或右键安排。人的快捷项为阅读、整理、提炼，SI 为整理、提炼，双方都可自定义。
- 标题栏按我／SI 和动作筛选。一个可选文本属性 `inbox-work` 保存当前安排，卡片与 `Inbox queue.base` 共用；在 Base 编辑后，卡片自动更新。
- 具体要求写在原笔记，结果回到实际资料与成果。选择 SI 只保存安排，不代表插件已启动外部助手。
- 有明确归属时，通过“移出 Inbox”选择已有目标目录。迁出保留正文并清除临时 `inbox-*` 字段，可用操作回执撤销。

迁出默认不留下入口。选择“留在 Inbox”后，会在 Inbox 目录的 `Inbox.md` 追加一条普通链接，可直接补充交接；不生成编号，也不继承旧安排。完成后清理该条，资料保留，可撤销。选择我／SI 时才写入可选的协作标记。自动触发尚未接通，选择 SI 不代表已启动执行。

### 11.4 使用任务看板

- 月表看长期分布；
- 周表安排近期节奏；
- 日表处理当天时段；
- 四象限重新判断优先级。

### 11.5 使用任务时间轴

1. 用今天、滚轮、空白拖动或底部导航定位范围。
2. 选择图层、完成态和标签筛选。
3. 点击标题或圆点打开来源，悬停或聚焦查看详情。
4. 需要调整任务排期时，使用任务的交互手柄。
5. 需要表达阶段而不改变任务日期时，添加命名的项目或全局时间标注。
6. 将常用的时间中心、尺度、图层和筛选条件保存为命名视图。

### 11.6 推进项目与知识积累

1. 在主页的项目区找到一个项目。首次初始化后，可以先使用空白的 Noria 工作区，也可在项目管理中创建自己的项目。
2. 在 **记下一步** 中输入具体行动。任务写入项目既有任务笔记和任务章节；有多个可选任务笔记时再选择位置。添加后立即可见，写入失败保留输入。
3. 点击任务标题，使用与看板相同的编辑器调整任务和日期；标签、优先级、重复及依赖也在同一处。源笔记图标直接打开原任务行。日期可留空，关闭后本次会话中的输入仍保留。
4. 勾选即可完成，也能从已完成项重开；通过**查看全部**展开其余清单。任务看板与 Timeline 读取同一条原始任务，未排期任务只有在你安排日期后才进入对应时段。

阶段输出继续维护在项目笔记中，可长期复用的结论再连接到对应 MOC。

![公共任务编辑器：日期与时间可以留空](../assets/zh-CN/workbench-task-editor.png)

### 11.7 使用习惯和趋势

主页提供今日打卡与近期记录，较长历史按需展开；更大范围的习惯历史和热力图放在趋势区。趋势更适合周复盘和月复盘，不用于每天评价自己。

### 11.8 接收外部简报

外部流程生成 Markdown，主页显示摘要和来源。阅读后再决定是否转为任务、项目材料或长期笔记。

### 11.9 完成日复盘

打开当天，阅读已有内容或开始书写，就近修改需要调整的部分。提纲和外部分析按需使用，最后明确保存到同一天的笔记。

### 11.10 周期复盘与调整

查看任务、项目、习惯、日态和趋势证据，区分已完成、仍有价值、需要调整和应当停止的事项，只保留少量下一阶段重点。

### 11.11 最小使用方式

```text
随手记录 → 选择一项任务 → 更新 Markdown → 必要时复盘
```

## 12. FAQ 与故障排查

### 12.1 统一排查顺序

1. **入口**：模块是否启用，打开的是否为预期视图。
2. **来源**：Markdown 是否存在、已保存且格式正确。
3. **范围**：路径、扫描范围、日期和标签筛选是否包含目标内容。
4. **刷新**：先使用界面刷新或重试，再重新打开视图。
5. **诊断**：到“维护”运行安装检查并保存报告。

不要一开始就删除 `data.json`、重建全部文件或重装插件。

### 12.2 视图打开后空白

检查插件和模块是否启用、路径是否缺失、视图是否仍在延迟加载，再使用“重试”或重新打开。任务时间轴若每次重启都必须先打开任务看板，属于启动恢复故障。

### 12.3 任务没有显示

检查标准任务语法、来源保存状态、扫描范围、包含与排除标签、日期范围，以及当前视图是否隐藏完成、取消、无日期或习惯任务。

### 12.4 看板、时间轴和日历不一致

先比较日期范围、完成态、标签筛选和无日期任务策略。三者使用同一任务事实，但展示目标不同，不能只比较条目数量。

### 12.5 时间轴加载慢或不能操作

确认不是诊断空壳，缩小任务扫描范围，减少无关图层，并检查来源冲突。持续空白、滚轮无响应或只能通过重新执行命令恢复时，应作为故障报告。

### 12.6 文件创建到了错误目录

检查“总览 → 路径”中的 Diary、Inbox、Projects、模板和清单路径。“替换全部路径”会切换整套引用，使用前先查看预览。

### 12.7 主页小组件没有内容

检查组件是否启用、来源路径是否存在、文件是否为空、简报是否过期，以及组件是否被隐藏。Markdown 过期时不应继续伪装成当前信息。

### 12.8 统计结果与预期不同

检查共享时间范围、任务完成日期、笔记扫描范围、日记命名、习惯来源和文件保存状态。数据不完整不等于零。

### 12.9 复盘无法保存或没有更新

检查目标周期笔记和路径。外部 Agent 更新后点击刷新；出现来源冲突时先比较目标笔记，不要强制覆盖。

### 12.10 天气没有显示

新安装默认关闭天气。启用后选择位置或城市，按 provider 需要配置 SecretStorage 凭据，再手动刷新验证。

### 12.11 外部简报没有显示

检查目标 `.md` 是否生成、来源路径和角色是否正确、修改时间是否超过新鲜度，以及正文是否为空。

### 12.12 恢复设置

优先使用设置备份、补齐缺失路径、恢复单个模块默认值或重新生成缺失文件。只有明确需要清空全部设置时才删除 `data.json`。

### 12.13 报告问题

提供 Noria、Obsidian 和操作系统版本、模块、最短复现步骤、截图、维护报告和相关控制台错误。不要提交 API 密钥、完整私人日记或无关知识库内容。

## 附录 B：高级与开发参考

### B.1 扩展边界

Noria 提供三类扩展方式：

1. Markdown 文件契约；
2. 版本化 JSON 导出；
3. 可信自定义 JavaScript view。

内部 DOM、CSS 类名、缓存实现、刷新 hook 和源码模块路径不属于稳定公共接口。

### B.2 自定义 JavaScript view

自定义 view 默认关闭。启用后，库内 JavaScript 会获得 Obsidian、Noria、`window` 和 `document` 的访问能力；它不是安全沙箱。

```js
const bridge = input.noriaBridge;
const result = await bridge.data.getSnapshot({
  preset: "home",
  range: { mode: "last30" }
});

const el = document.createElement("pre");
el.textContent = JSON.stringify(result.range, null, 2);
input.mount.appendChild(el);
```

只运行自己编写或已经审查的代码，并优先使用注入的 `input.noriaBridge`。

### B.3 公共 Data API

体验版本另提供外部调用入口 `app.plugins.plugins.noria.api`（version 1），支持任务查询／改期／状态修改、按日期读取／更新“建议”章节。输入、冲突、刷新及生命周期说明见 [外部 Agent API](../AGENT-API.md)。原有 Data API 保持如下；任务写入使用新接口返回的 `ref`，不能直接传入 Data API 的 `identity`。

```js
bridge.data.resolveRange(request)
bridge.data.getSnapshot(request)
bridge.data.getTasks(request)
bridge.data.getTimelineAnnotations(request)
bridge.data.getTimelineTraces(request)
bridge.data.getPeriods(request)
bridge.data.getReviewEvidence(request)
bridge.data.export(request)
```

`data.invalidate()` 是内部刷新 hook，不作为公共接口承诺。

### B.4 范围与 preset

范围支持 `last30`、`week`、`month`、`year`、`custom` 和 `homeCurrent`。内置 preset 包括 `home`、`board`、`timeline`、`periodic`、`review` 和 `exportAll`。

### B.5 Snapshot

```json
{
  "meta": { "schemaVersion": 1, "request": {}, "resolvedRequest": {}, "policy": {} },
  "range": {},
  "granularity": "day",
  "domains": {},
  "views": {},
  "warnings": [],
  "sourceCompleteness": {}
}
```

调用方必须检查 `schemaVersion`、`warnings` 和 `sourceCompleteness`。

### B.6 任务事实与写回

任务身份由以下信息共同确定：

```text
sourcePath + line/blockId + fingerprint
```

写回必须定位原 Markdown、检查来源指纹、只修改目标任务行，并在来源变化时拒绝覆盖。渲染器本身不直接改写知识库。

### B.7 JSON 导出

```json
{
  "exportKind": "noria.snapshot",
  "exportVersion": 1,
  "exportedAt": "",
  "noriaVersion": "0.4.6",
  "payload": {}
}
```

支持 `noria.snapshot`、`noria.tasks` 和 `noria.reviewEvidence`。外部工具应根据 `exportKind` 和 `exportVersion` 解析。

### B.8 兼容性

扩展应检查 `bridgeVersion` 和数据 `schemaVersion`，对可选字段进行特性检测，不依赖内部属性顺序，不直接修改 `data.json`，也不读取或输出 SecretStorage 凭据。

### B.9 源码验证

```bash
npm ci
npm run build
npm test
npm run release:check
```

公开安装包只包含 `manifest.json`、`main.js` 和 `styles.css`。


### 自定义图样与日期导航

卡片设置、习惯设置、记录项目和状态外观使用同一个图样选择器。可以搜索应用提供的通用图标、输入 Emoji，或选择仓库内图样目录中的 PNG、JPEG、WebP、SVG。目录支持子目录筛选；图片以原色显示，线性图标沿用内容配色。图片引用跟随仓库内的文件或目录重命名；文件被删除时显示缺失提示，可重新选择或恢复默认。

主页卡片在“卡片设置”中更换图样；日记内置卡片通过右上角菜单的“更换图样”调整，同一日／周／月／年布局共用。操作按钮图标保持一致，不随内容图样改变。

日记日期条两侧箭头翻动一组日期，下方同一行放范围标题、周期切换、回到今日／本周／本月／本年及文档操作。窄卡保留编辑按钮，次要操作收进“更多”。点击范围标题打开现有侧栏日历，保持日期网格；月／年标题打开列表，点选即进入对应月记／年记，列表保留；顶部中间的日历图标仅负责返回日期网格。复盘操作与“复盘”标题同排。

内置主页、日记、待办日历、Timeline 和统计视图无需 Dataview 即可运行。用户自行编写的 Dataview 查询仍可选用该插件；Noria 原生数据查询不依赖它。新增习惯按含义选择默认图样，已经明确选择的图样和颜色会保留。

日常统计的等级记录采用紧凑色带，连续数值保留趋势；空数据不算零。展开习惯历史后，历史连续段末块从 2 起显示连续数量，按完整历史和当时的打卡计划计算，不受显示窗口限制。今天列始终显示实际记录值或打卡状态，不用连续次数替代。

### 卡片布局操作

功能图样始终位于标题最左，常用动作靠右，`…` 菜单在最右。通过菜单收起或展开卡片；收起后标题和菜单仍可用。日记的记录与复盘也从各自的 `…` 菜单收起或展开，收起前会保存编辑，保存失败时保持内容可见。拖动标题栏空白处可排序，文字、链接与按钮保留原操作。拖动右侧外缘预览吸附后的宽度，松手保存，Esc 取消。窄窗口下卡片仍按响应式布局显示；菜单的“布局”子菜单可以设置较宽视图中的首选宽度。底边高度拖动不要求先进入布局编辑模式。

标题菜单保留内容管理和卡片设置。“布局”子菜单统一提供窄／中／宽／整行、上移、下移、自动高度、收起／展开，以及支持的复制卡片和移出本页；每项使用图标配短名称，当前宽度显示勾选。移出本页保留配置、内容和位置，可撤销，也可以从添加卡片中的“恢复”入口恢复，不再区分隐藏与移出。日记的任务、习惯、记录、复盘均可在卡片设置中修改名称和图样；这不会改写源笔记的标题或正文。宽度只在布局中设置。聚焦宽度手柄后用左右键调整，键盘或触屏可用菜单的上下移选项排序；高度手柄的 Home 键恢复自动高度。日／周／月／年日记布局仍各自共用。

心情默认采用统一表情系列，精力采用五级太阳图样，专注采用聚焦圆环；未填写时淡显。默认图样也可在共用选择器中选取，项目图样和各状态图样、名称仍可自定义。旧的内置默认图样采用新外观，自定义图片与状态覆盖保留。

专注记录新写入 Markdown 的起止时间最多到秒，不显示毫秒；跨日保留日期，暂停时段分开记录。旧的毫秒记录继续可读，不批量改写。内部计时仍使用毫秒，避免影响暂停和恢复；汇总显示按场景使用分钟或小时。
